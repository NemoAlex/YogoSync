# YOGO Pet 0.1.0

Codex 任务状态 → 本地控制程序 → YOGO 75 PRO 2.4G 接收器 → 6×6 点阵图标。

## 运行本地程序

安装 Node.js 22+，在此目录执行：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:19775 ，点击「连接 YOGO 接收器」。
请关闭 ATK 的设备设置页，避免同时控制。正常退出会恢复原灯效；异常退出后再次连接会从本地备份恢复。

## 安装 Codex 插件

通过分享的插件入口安装 YOGO Pet，然后在 Codex 的 Hooks 审核入口信任它；CLI 可输入 `/hooks` 审核。
安装后在新任务中测试。插件安装不会自动启动本地硬件程序，两者需在同一台电脑上运行。

插件只记录事件名、随机任务标识和时间，不保存提示词、工具参数或对话文件。事件写入 `~/.local/share/yogo-pet/events/`，由本地程序消费后删除。
